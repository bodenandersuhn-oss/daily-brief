Privacy Policy

Daily Brief · Last updated 8 September 2026
Daily Brief is a personal, single-user project. It is run by one person for their own use and has no other users, no operators, and no commercial purpose.

What this app is

Daily Brief assembles a weekday news summary from public RSS feeds and from newsletter emails in the operator's own Gmail account. It runs as a scheduled job on GitHub Actions and publishes a static page to GitHub Pages.

What data it accesses

The app requests one Google account permission, gmail.readonly, which allows reading Gmail messages. It is used only to find newsletter emails matching a fixed list of sender and subject queries — specifically, Wall Street Journal newsletters the operator has subscribed to.

  • Only messages matching those queries are read.
  • Only the headline links and short blurbs inside those newsletters are extracted.
  • The app never sends, modifies, deletes, or labels any email. The permission is read-only.
  • No other Google data — contacts, calendar, files, profile — is requested or accessed.

How data is stored and shared

Extracted headlines and links are combined with public RSS items, summarized, and written to a public web page of news headlines. Email addresses, message bodies, attachments, and message identifiers are not published and not retained. A local database stores only headline text and URLs, to avoid repeating the same story on later days.

Data is not sold, rented, or shared with third parties. Headlines and blurbs are sent to the Anthropic API solely to generate the summaries that appear on the page.

Google OAuth credentials are stored as encrypted GitHub Actions secrets and are never written to the repository or displayed on the published page.

Retention and revocation

Access can be revoked at any time from Google Account permissions, which immediately and permanently ends the app's ability to read any email.
